### Quadratic Equation Solver (Завдання 11)
Консольна програма для розв'язання квадратних рівнянь виду ax² + bx + c = 0.
### Як влаштований проєкт
Код розбитий на 3 окремі класи за логікою завдання:
* `EquationTask` — зберігає коефіцієнти a, b і c, які ввів користувач (ініціалізуються через конструктор).
* `EquationResult` — клас під результат. Зберігає кількість коренів (0, 1 або 2) та самі знайдені значення. Під різні випадки зроблені окремі конструктори.
* `EquationSolver` — рахує рівняння. Розрахунок дискримінанта схований у private-метод, а назовні доступний лише загальний метод `Solve()`, який приймає задачу й повертає результат.

У `Program.cs` організовано введення даних із консолі, перевірку на `a == 0` (щоб рівняння не вироджувалося в лінійне) та виведення відповіді.
